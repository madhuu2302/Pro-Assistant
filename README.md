# PRO ASSISTANT – AI-Powered Prompt Engineering Assistant

## About the Project

PRO ASSISTANT is an AI-powered web application built using Python and Streamlit. It uses Google Gemini AI to generate responses based on different prompt engineering techniques.

Users can enter a task, select a prompt engineering technique, and generate responses through a simple and interactive interface.

## Features

- Zero-shot Prompting
- Few-shot Prompting
- Chain-of-Thought Prompting
- Role-Based Prompting
- Summarization
- AI-generated responses using Google Gemini
- Simple and user-friendly interface

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google Gen AI SDK
- Python Dotenv

How to Use
Open the PRO ASSISTANT application.
Select a prompt engineering technique.
Enter your task in the text box.
Click the Generate Response button.
View the AI-generated response.

Example

Selected Technique: Zero-shot Prompting

Input:
Explain Artificial Intelligence in simple English with three real-life examples.

Output:
The application generates an AI response explaining Artificial Intelligence and providing relevant examples.
